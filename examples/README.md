# Examples

Worked examples of using dapkel, as Jupyter notebooks — to be added.

What belongs here: a notebook that runs end to end on data anyone can point it
at, with the paths as the only thing a reader has to change. What does not:
bench scripts with hardcoded paths, or functions pasted inline to be stepped
through. Those are development scratch and live outside the repo.

Until then, the [documentation](https://rngkomorebi.github.io/dapkel/) carries a
runnable snippet for every analysis, and the
[quick start](../README.md#quick-start) is the shortest path from a folder of
`.bin` files to a figure.
